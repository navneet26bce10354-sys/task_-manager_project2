# Student Task Manager (CLI)

A simple Command Line Interface (CLI) application built using Python to help college students track their daily assignments and study tasks.

## Features
- **Add a new task:** Enter task name, subject, and status (Pending/Done).
- **View all tasks:** See a clean list of all your entered tasks.
- **Task Summary:** Check how many tasks are completed and how many are pending.

## How to Run
1. Ensure Python 3 is installed on your system.
2. Open the terminal or command prompt in the project folder.
3. Run the following command: `python main.py`

## Technologies Used
- Core Python 3
- File Handling (.txt)
